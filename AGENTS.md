# ColdSafe — instruções do projeto

As instruções globais do usuário continuam válidas.

## Contexto

- Consulte [docs/README.md](docs/README.md) para encontrar a documentação do
  projeto. Abra arquivos, referências de skills e evidências sob demanda.
- Use codebase-memory-mcp para descobrir código e indexe se necessário. Busque
  textos, estilos, documentação e configuração diretamente nos arquivos.
- A pasta do projeto é a fonte atual. O Notion guarda referências legadas.
  Confira no código ou nos testes as alegações dos documentos antes de usar seus comandos.

## Execução e validação

- Explique o plano antes de editar. Preserve as mudanças locais, prefira
  mudanças pequenas e registre dependências novas.
- Execute diretamente por padrão. Delegue quando houver ganho claro em uma
  dúvida especializada, revisão independente ou trabalho separável. Passe um
  resumo curto, delimite a responsabilidade e evite edições concorrentes.
- Rode os testes afetados durante a edição. No fim, faça o build e os testes
  que o escopo exigir. Rode Playwright depois do build com a configuração de
  API da suíte. Mostre totais e trechos relevantes das falhas. Em UI, use uma
  captura desktop representativa e adicione outra se o aceite exigir.
- Registre resultado, testes executados, limites e próxima etapa no cartão
  da tarefa, quando houver. Distinga plano, resultado e evidência anterior.
  Atualize o índice quando o status mudar. Use Ponytail e ECC strategic-compact. Registre o ponto de
  retomada antes de compactar ou trocar de chat. Aguarde a escolha da próxima etapa.
