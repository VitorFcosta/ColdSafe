Leia somente a linha relevante. Uma tarefa concluída como documento não comprova
a funcionalidade planejada. Resultados antigos têm data e escopo; não são testes
realizados na sessão atual.

Documentação e contratos editáveis ficam em Markdown/JSON. O arquivo de segurança
do Notion no histórico serve apenas para recuperação; não é leitura de retomada.
