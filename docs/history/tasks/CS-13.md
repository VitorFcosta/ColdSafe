# CS-13 — Implementar MQTT QoS 1 e reconexão

- **Status:** Concluída
- **Dependências:** Configurar Wokwi VS Code e gateway privado
- **Frente / prioridade:** IoT / P0

## Aceite

Payload versionado chega a cada 5 s e o cliente se recupera de desconexão.

## Evidência de conclusão — 07/09/2026

- Firmware passou a autenticar no Mosquitto como `coldsafe-device` e usar o identificador `esp32-lab-01`.
- Telemetria publicada em `coldsafe/v1/telemetry` a cada 5 segundos com QoS 1.
- Payload observado: `{"schema_version":1,"device_id":"esp32-lab-01","temperature_c":5.4,"humidity_percent":62.1}`.
- Leitura local do DHT22 preservada a cada 2 segundos; leituras inválidas não são publicadas.
- Reconexões Wi-Fi e MQTT usam tentativas temporizadas, sem laço bloqueante.
- Mosquitto reiniciado durante a simulação; o ESP32 reconectou sem reiniciar e retomou as publicações.
- Assinante real recebeu pacote `q1` e enviou `PUBACK`.
- Duas mensagens consecutivas foram recebidas com intervalo de 5 segundos.
- Firmware compilado com sucesso para ESP32: 13,8% de RAM e 57,4% de flash.
- Suíte completa: `167 passed, 2 skipped`.
