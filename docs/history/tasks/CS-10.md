# CS-10 — Criar circuito ESP32 e DHT22

- **Status:** Concluída
- **Dependências:** Inicializar Git e estrutura do monorepo
- **Frente / prioridade:** IoT / P0

## Aceite

Sensor é alterável no simulador e a leitura aparece no serial.

## Evidência de conclusão — 07/09/2026

- Projeto PlatformIO criado em `firmware/` para ESP32 DevKit.
- DHT22 ligado em `3V3`, `GND` e `GPIO 15`.
- UART do ESP32 ligada ao `$serialMonitor` (`TX → RX` e `RX → TX`).
- Sensor configurado no Wokwi com temperatura `5.4 °C` e umidade `62.1%`, valores alteráveis durante a simulação.
- Saída observada: `temperature_c=5.4 humidity_percent=62.1`.
- Firmware compilado com sucesso pelo comando `~/.platformio/penv/bin/pio run --project-dir firmware` a partir da workspace principal ColdSafe.
Critério de aceite comprovado no Wokwi VS Code.
