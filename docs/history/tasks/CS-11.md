# CS-11 — Configurar Wokwi VS Code e gateway privado

- **Status:** Concluída
- **Dependências:** Criar circuito ESP32 e DHT22
- **Frente / prioridade:** IoT / P0

## Aceite

ESP32 alcança host.wokwi.internal e o Mosquitto local.

## Evidência de conclusão — 07/09/2026

- Wokwi Simulator 3.7.0 executado no VS Code com os artefatos do PlatformIO.
- Monitor serial e porta RFC2217 local `4000` validados.
- ESP32 conectado ao `Wokwi-GUEST` com IP `10.13.37.2`.
- Firmware realizou uma sondagem TCP em `host.wokwi.internal:1883`.
- Mosquitto local registrou a conexão da ponte Docker em `172.18.0.1`, comprovando o caminho simulador → host → container.
- Firmware compilado em C++17 sem avisos.
- Suíte completa: `166 passed, 2 skipped`.
- Teste estrutural específico do firmware: `7 passed`.

## Limitação conhecida

A licença Wokwi Community não permite ativar o rótulo pago **Private IoT Gateway**. A interface permanece indicando **Public IoT Gateway**, mas o critério de aceite foi comprovado funcionalmente pelos logs do Mosquitto local.
Critério de aceite cumprido: o ESP32 alcança `host.wokwi.internal` e o Mosquitto local. A autenticação, publicação MQTT QoS 1 e reconexão pertencem à CS-13.
